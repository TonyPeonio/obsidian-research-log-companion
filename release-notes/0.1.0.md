First release.

- **Log an experiment / result / decision / idea**: two fields (what, notes); the plugin appends an entry to the project's log note with the git branch, short commit and dirty state, up to 12 parameters from the newest changed config or job file (`.yaml .yml .json .toml .ini .cfg .env .sh .slurm`), the command line from shell/SLURM scripts, data files changed since the previous entry with size and sha256 (first 64 MB), and new figures. Append-only: nothing is ever rewritten.
- **Show project timeline**: entries by ISO week, newest first, with type counts, each linked to its heading.
- **Compare two runs**: table of differences in commit, parameters (numbers compared by value), data hashes and figures.
- **Find runs by parameter**: `lr=3e-4 batch=64` or a bare key.
- **Write this week's report**: Summary / Results / Decisions / Open questions from the last 7 days (or since the last report) with a local Ollama model; every bullet cites its entry, and missing or invented citations are flagged.
- **Export reproducibility card**: one page per run or result with commit, repository link, command, parameters, data hashes, figures and notes.
- Settings: several projects, each with a log note, code repository, watched data folders and figures folder; Ollama URL and model for the report only.
